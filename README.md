# DevTask — Developer Task Manager

A small website where developers create tasks, organize them, and track their progress.

## Features

- Create, edit, delete, and complete tasks.
- Filter by status, priority, and deadline.
- Search tasks.
- Show progress statistics.

## Backend

REST API with database CRUD, filtering, validation, and error handling.

## Programmer mindset

Learn how to break a big problem into small functions and handle all the different states of a task.
